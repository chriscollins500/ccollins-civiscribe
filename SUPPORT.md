# Getting help with CiviScribe

Start at the [project hub](https://chriscollins500.github.io/ccollins-civiscribe/guides/project-hub/)
for downloads, guides, the roadmap, and community spaces. The
[searchable field guide](https://chriscollins500.github.io/ccollins-civiscribe/guides/)
and [interactive playground](https://chriscollins500.github.io/ccollins-civiscribe/playground/)
can help you explore a setting before changing a workflow.

The [CiviScribe wiki](https://github.com/chriscollins500/ccollins-civiscribe/wiki)
covers installation, every setting, filenames, counters, workflow connections,
dynamic prompts, resource identities, metadata, and troubleshooting.

## Ask a question

Use [GitHub Discussions](https://github.com/chriscollins500/ccollins-civiscribe/discussions)
for usage questions, workflow advice, ideas, and examples of what you have made.
The Q&A category supports marking an answer when a solution works.

## Report a bug

Open a [bug report](https://github.com/chriscollins500/ccollins-civiscribe/issues/new?template=bug_report.yml)
with the installed CiviScribe and ComfyUI versions, steps to reproduce, expected
result, and actual result. Relevant node class names and a small synthetic or
redacted workflow help make the problem reproducible.

For metadata problems, enable **Write sidecar JSON** and inspect the diagnostic
codes and the affected resource's status. Review anything you attach for
private prompts, model paths, images, workflows, tokens, and credentials.

## Suggest an improvement

Start an [Ideas discussion](https://github.com/chriscollins500/ccollins-civiscribe/discussions/categories/ideas)
or submit an [improvement request](https://github.com/chriscollins500/ccollins-civiscribe/issues/new?template=feature_request.yml).
Explain what you are trying to accomplish and the behavior that would help.

## Report a security vulnerability

Use [private vulnerability reporting](https://github.com/chriscollins500/ccollins-civiscribe/security/advisories/new)
to send a confidential report to the maintainer. Include a minimal explanation
and reproduction steps. The security policy describes the trust boundaries
and release-verification process.
[Security policy](SECURITY.md)
