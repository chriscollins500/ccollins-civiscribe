What can I put in a pattern?
%model%%model_noext%%seed%%sampler%%width%%height%%batch_num%%date:yyyy-MM-dd%%counter%%counter:4%

%model% keeps the model extension. %model_noext% removes one recognized model extension. Without a counter token, the familiar _00001_ suffix stays. Use one counter token in the filename, with a minimum width of 1–9.
