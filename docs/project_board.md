CiviScribe saves high-quality images with accurate generation metadata in
current ComfyUI Desktop. This board records accepted priorities, ideas under
consideration, and completed software or documentation work.

## How to read the board

- **Planned:** accepted maintenance priorities or scoped upcoming work.
- **In progress:** work has started.
- **Under consideration:** an idea, not a promise to implement it.
- **Done:** released software or deployed documentation with evidence links.

The [roadmap guide](https://chriscollins500.github.io/ccollins-civiscribe/roadmap/)
is the source for priorities, product boundaries, and status meanings. Future
ideas have no promised date or version until explicitly scheduled. Release
dates use America/New_York, matching the dated changelog sections.

Documentation can deploy without a node-version release. Software releases
remain in the [changelog](https://chriscollins500.github.io/ccollins-civiscribe/changelog/)
and [GitHub releases](https://github.com/chriscollins500/ccollins-civiscribe/releases).
The Registry may take time to process a new release.
