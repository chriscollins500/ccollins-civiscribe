# Community guidelines

CiviScribe welcomes questions, bug reports, ideas, code, documentation, and
workflow examples from people of all backgrounds and experience levels.

## Working together

- Treat people with respect and focus feedback on the idea, code, or behavior.
- Give enough context for others to reproduce a problem or understand a suggestion.
- Respect creators' licenses and credit the resources used in shared work.
- Obtain permission before sharing someone else's personal information or private content.
- Keep harassment, threats, impersonation, and targeted abuse out of project spaces.

These guidelines apply to this repository's issues, pull requests, discussions,
and other spaces maintained for CiviScribe.

## Moderation and concerns

The repository maintainer may edit or remove disruptive content, close a
conversation, or restrict participation to protect the community. Responses
should be proportionate to the behavior and its impact.

Use GitHub's **Report content** or **Report abuse** controls for a conduct
concern. GitHub Support can receive a private report when public discussion
would expose sensitive information. Security vulnerabilities have a dedicated
private reporting route described in the security policy.
